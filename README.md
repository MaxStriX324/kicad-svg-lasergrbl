# KiCad SVG → PNG 1:1 для LaserGRBL / CNC3018

Пакетная конвертация экспортированных из **KiCad 10** файлов `.svg` в монохромные `.png` для **LaserGRBL 4.9.4** (Windows). Для каждой платы создаётся отдельный TXT с физическими размерами и инструкцией по импорту; общий отчёт автоматически открывается в Блокноте.

**Назначение:** обработка слоя меди / маски лазером, например удаление защитной краски перед травлением. В стандартной полярности **чёрное — обрабатываемая область, белое — не обрабатывается**. Полярность следует проверять для конкретной технологии и настроек импорта.

## Быстрый запуск (Windows)

1. Скачайте проект через **Code → Download ZIP**, распакуйте.
2. Один раз запустите `install.cmd`: он создаст локальную `.venv` и установит Python, PyMuPDF и Pillow при необходимости. Потребуется интернет.
3. Экспортируйте нужные слои из KiCad в **SVG**, включив *Fit page to board* (подгонку страницы к плате).
4. Скопируйте все SVG в папку с `start.cmd`.
5. Запустите **`start.cmd`**. Каждый SVG будет преобразован независимо, даже если размеры плат различаются.

Получите:

| Вход | Выход |
|---|---|
| `F_Cu.svg` | `F_Cu_laser.png`, `F_Cu_laser_settings.txt` |
| `B_Cu.svg` | `B_Cu_laser.png`, `B_Cu_laser_settings.txt` |
| Все SVG | `LASERGRBL_SETTINGS.txt`, `lasergrbl_sizes.csv` |

Настройки задаются в начале `start.cmd`:

```bat
set "DPI=508"
set "INVERT=0"
set "MIRROR_X=0"
set "THRESHOLD=128"
```

- **508 DPI** = номинально 20 пикселей/мм, шаг 0,05 мм.
- `INVERT=1` меняет чёрное и белое.
- `MIRROR_X=1` отражает изображение по горизонтали. Не включайте зеркало автоматически для обратного слоя: ориентируйтесь на технологию установки платы.
- `THRESHOLD` задаёт порог чёрно-белого растра.

## LaserGRBL 4.9.4: импорт 1:1

1. **File → Open File** → `*_laser.png`.
2. В окне импорта растра можно выбрать **Line To Line Tracing**; проверьте, какие области будут гравироваться.
3. В **Target Image** отключите **Autosize**, вручную установите **Size W**, указанную в `*_laser_settings.txt`, и проверьте **Size H**.
4. Если размер изображения фиксирован по пропорциям, высота может отличаться от исходного SVG на несколько микрометров. Точная рассчитанная разница указывается в отчёте.
5. Не включайте Crop/Auto crop, дополнительное масштабирование, поворот или зеркало без необходимости.
6. Проверьте *frame* при выключенном луче, калибровку GRBL `$100`/`$101`, масштаб по тестовому размеру и диаметр пятна лазера.

**Точность:** утилита считывает физические размеры **страницы SVG**, не обрезает её и рассчитывает растровую сетку, близкую к заданному DPI. Это не означает гарантированную точность станка 1:1: механическая калибровка и масштаб импорта должны быть проверены. Если KiCad экспортировал поля вокруг платы, они входят в размеры; для реального контура применяйте *Fit page to board*.

## Запуск из командной строки

После `install.cmd`:

```bat
.venv\Scripts\python.exe svg_to_png_batch.py --dpi 508 --invert 0 --mirror-x 0 --threshold 128
```

Конвертер обрабатывает все `.svg` **рядом с самим Python-скриптом**. Для другой папки предусмотрен `--folder "C:\path\to\svg"` (не добавляйте `\` непосредственно перед закрывающей кавычкой). Некорректные единицы размера SVG отклоняются с ошибкой, а не угадываются.

## Проверка

```bat
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты проверяют единицы измерения, пиксельный масштаб, чёрно-белый вывод, инверсию и создание отчёта. Данные пользовательских плат не включены в репозиторий. Сгенерированные PNG/TXT, исходные SVG и виртуальное окружение исключены через `.gitignore`.

Для деталей на русском также имеется `README_RU.txt`.
