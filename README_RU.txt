KiCad 10 -> SVG -> PNG + TXT -> LaserGRBL 4.9.4 / CNC3018
Версия 4: папки проектов, PNG + NC, размеры плат и отчёты
=====================================================================

УСТАНОВКА:
  1. Распаковать архив в папку.
  2. Первый раз запустить install.cmd (установит Python и библиотеки).
     При удалённом/обновлённом Python повреждённая .venv автоматически
     пересоздаётся. Установка не удаляет пользовательские SVG/PNG/TXT.
  3. Копировать все SVG экспортированные KiCad в эту же папку.
  4. Дважды щёлкнуть start.cmd. При проблеме с Python этот файл
     автоматически запустит восстановление окружения.
  5. Для EVSE-F_Cu.svg и EVSE-B_Cu.svg создастся папка _EVSE.
     Оба SVG перемещаются в неё после создания PNG и NC.

РЕЗУЛЬТАТ:
  _EVSE/ — отдельная папка с исходными слоями меди F_Cu/B_Cu
  EVSE-F_Cu.svg -> EVSE-F_Cu_laser.png
                -> EVSE-F_Cu_laser.nc
                -> EVSE-F_Cu_laser_settings.txt
  EVSE-B_Cu.svg -> EVSE-B_Cu_laser.png
                -> EVSE-B_Cu_laser.nc
                -> EVSE-B_Cu_laser_settings.txt
  LASERGRBL_SETTINGS.txt — отчёт в папке проекта и общий в корне
  lasergrbl_sizes.csv — размеры для Excel

В начале start.cmd можно изменить DPI, INVERT, MIRROR_X, THRESHOLD.
Также GCODE_LINES_PER_MM=10 (шаг 0,1 мм),
GCODE_FEED=1000 (мм/мин), GCODE_POWER=1000 (S-код).
  DPI=508       ~20 пикселей/мм (лазерный шаг 0,05 мм)
  INVERT=0      при 1 инвертировать белый/чёрный
  MIRROR_X=0    при 1 отразить слева направо
  THRESHOLD=128 порог перевода в чёрно-белое

В LaserGRBL 4.9.4:
  File -> Open File -> *_laser.png
  Import Raster Image -> Line To Line Tracing -> Next
  Target Image -> снять Autosize -> указать Size W из TXT.
  Размер Size H перепроверить по отчёту, потому что LaserGRBL
  сохраняет соотношение сторон PNG и пересчитывает H сам.

ВАЖНО О ТОЧНОСТИ:
  Отчёт показывает размеры СТРАНИЦЫ SVG KiCad. Включайте при экспорте
  подгонку страницы к плате, чтобы не гравировать большие поля.
  PNG имеет целое число пикселей. Конвертер выбирает близкую
  к указанному DPI сетку с минимальным расхождением пропорций.
  TXT показывает отклонение H после установки W; оно не скрывается.
  Реальная точность CNC3018 зависит от $100/$101 (GRBL), люфтов,
  калибровки шагов/мм, пятна лазера и правильного масштаба в LaserGRBL.
  Скорость, мощность, зеркальность и полярность зависят от метода
  изготовления плат — скрипт их не угадывает.
Для .nc ноль X0/Y0 находится в левом нижнем углу SVG-страницы.
Растр идёт горизонтально снизу вверх змейкой, чёрное = лазер включён,
белое = лазер выключен. Используются G21, G90, G94, M3, M5; без Z.
Перед запуском проверьте $30, $32 и сделайте холостой проход без луча.
Если $30=255, задайте GCODE_POWER=255; S1000 не универсален.
Файл .lps — бинарный проект LaserGRBL, программа его не создаёт.
